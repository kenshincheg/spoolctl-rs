# SpoolCtl 0.1.15 (стабильный выпуск)

Portable-утилита для службы печати Windows (Spooler).

## Что для какой Windows

| Путь в архиве | Система | Как пользоваться |
|---------------|---------|------------------|
| `SpoolCtl.exe` (корень) | **Windows 10 / 11** | Двойной щелчок — окно; закрытие → спросить трей / выход |
| папка **`Windows7-CLI\`** | **Windows 7 x64** | `status.cmd` / `restart.cmd` / `fix.cmd` (GUI нет) |

## Изменения с 0.1.8 → 0.1.15

- **0.1.9–0.1.10** — автозапуск с Windows: задача Планировщика `/RL HIGHEST`, старт в трее уже elevated
- **0.1.11** — диалог закрытия: Отмена / В трей / Закрыть; одинаковая высота кнопок
- **0.1.12–0.1.13** — действия со службой: иконки 2×3; «От админа» в шапке; UAC → окно на экране (`--show`)
- **0.1.14** — скруглённые кнопки
- **0.1.15** — более светлый фон (светлая тема)

## Возможности стабильной сборки

- Статус / старт / стоп / перезапуск Spooler; очистка очереди (± перезапуск)
- Список принтеров и заданий; сторож зависания + автоперезапуск (с согласием)
- Трей, single-instance, UAC, elevated-автозапуск
- Утилиты: журнал, папки очереди/принтеров, откл. NcdAutoSetup

## Проверка целостности

SHA256 рядом с ZIP в `dist\`.
