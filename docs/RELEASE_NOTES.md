# SpoolCtl 0.1.8 (стабильный выпуск)

Portable-утилита для службы печати Windows (Spooler).

## Что для какой Windows

| Путь в архиве | Система | Как пользоваться |
|---------------|---------|------------------|
| `SpoolCtl.exe` (корень) | **Windows 10 / 11** | Двойной щелчок — окно; закрытие → трей |
| папка **`Windows7-CLI\`** | **Windows 7 x64** | `status.cmd` / `restart.cmd` / `fix.cmd` (GUI нет) |

## Изменения 0.1.8

- Трей: ЛКМ / «Показать окно» разворачивает; ПКМ → «Выход» закрывает
- Повторный запуск поднимает окно из трея
- Компактное окно + скролл; сторож зависания; IP/WSD; NcdAutoSetup

## Проверка целостности

SHA256 рядом с ZIP в `dist\`.
