# Windows 7 x64

## Где лежит сборка для Win7

В portable-архиве откройте папку **`Windows7-CLI\`** — она помечена для Windows 7.

| Файл | Назначение |
|------|------------|
| `ЧИТАЙ-МЕНЯ.txt` | краткая инструкция |
| `status.cmd` | статус Spooler |
| `restart.cmd` | перезапуск (администратор) |
| `fix.cmd` | очистка очереди + перезапуск (администратор) |
| `smoke.cmd` | базовая проверка CLI |
| `SpoolCtl.exe` | тот же бинарь; на Win7 только через команды выше |

Корень архива (`SpoolCtl.exe` без папки) — для **Windows 10 / 11** (GUI).

## Что поддерживается

| Компонент | Win7 x64 | Win10 / 11 x64 |
|-----------|----------|----------------|
| CLI | Да | Да |
| GUI | Нет | Да |
| Журнал | Да | Да |

## Smoke-проверка

На Win7 x64 из `Windows7-CLI\`:

1. `smoke.cmd`
2. От администратора: `restart.cmd`, при необходимости `fix.cmd`

## Ограничения

- Win7 x86 не входит в v1.
- Двойной щелчок по EXE на Win7 покажет подсказку использовать CLI.
