# Журнал разработки SpoolCtl

## 2026-09-18 — фиксация стабильной 0.1.8

- Закрыта ветка доработок трея/сторожа/UI как стабильный выпуск.
- Portable ZIP: корень Win10/11 + папка `Windows7-CLI` (тот же EXE, только CLI).
- Дальше: 0.1.9 — автозапуск с Windows.

## 2026-09-18 — выпуск 0.1.8: трей показать/выход

- Трей переписан на `Shell_NotifyIcon` + message-only HWND в отдельном потоке.
- Balloon при скрытии; старт окна ~640–700 px по высоте, скролл до нижних кнопок.

## 2026-09-18 — выпуск 0.1.6: трей

- Иконка в системном трее (`tray-icon` + Win32 ShowWindow).
- Закрытие окна → скрытие в трей; сторож и опрос продолжают работать.
- Меню: Показать / Скрыть / Выход; ЛКМ по иконке — показать окно.
- Single-instance находит и скрытое окно в трее.

## 2026-09-18 — выпуск 0.1.5: сторож зависания

- Модуль `watchdog`: слежение за очередью (без прогресса ~90 с) и pending Spooler (~60 с).
- Галочки в GUI: «Следить…» и «Автоперезапуск…» (подтверждение с предупреждением).
- Кулдаун 180 с между автоперезапусками; настройки в `spoolctl-settings.txt`.

## 2026-09-17 — UI: папка принтеров + откл. NcdAutoSetup

- Кнопки внизу: «Папка принтеров» (`shell:PrintersFolder`) и «Откл. автонастройку» (реестр AutoSetup=0 + служба NcdAutoSetup).
- Для WSD/IPP без IP в порте: подпись «сеть · WSD (IP в порте нет)»; IP показывается снова, когда порт TCP/IP.
- Скрипт: `tools\disable-ncd-autosetup.ps1`.

## 2026-09-17 — UI: панели + тип принтера по порту/IP

- Принтеры: правая `Panel`, список вниз (имя / сеть·IP или локальный / задания).
- Нижние кнопки: закреплённая панель, ширина ограничена (не на весь экран).
- Тип принтера по имени порта (IP_/WSD/TCP/USB…), показ IPv4 рядом с сетевыми.

## 2026-09-17 — выпуск 0.1.4

- Список принтеров (локальный/сеть) с числом заданий в GUI и CLI `status`.
- `list_printers` / `PrinterEntry` на Winspool; общая сводка очереди без двойного Enum.

## 2026-09-17 — fix: очередь без админа

- Без прав: больше не сырой «os error 5», а понятный текст + счётчик **заданий** через Winspool.
- С админом: «файлов нет» при пустой папке — нормально; показываем задания API и файлы на диске.

## 2026-09-17 — выпуск 0.1.3

## 2026-09-17 — GUI: только очистка очереди + отчёт

## 2026-09-17 — fix: GUI без OpenGL 2.0

## 2026-09-17 — fix: UAC после single-instance

## 2026-09-17 — этап 2: очистка очереди

- Модуль `queue`: stop → удаление файлов в `%SystemRoot%\System32\spool\PRINTERS` → (для `fix`) start.
- CLI: `clear-queue` (оставить остановленным), `fix` (очистить + перезапустить); отчёт deleted/failed.
- GUI: кнопка «Очистить очередь и перезапустить» с подтверждением.
- Тесты: удаление только файлов во временной папке; путь PRINTERS.

## 2026-09-17 — светлая/тёмная тема + подсказки

## 2026-09-17 — GUI (проверка ядра) + иконка EXE

- GUI на `eframe` + Glow (без wgpu): статус, кнопки Обновить / Запустить / Остановить / Перезапустить.
- Без аргументов — окно; с аргументами — CLI (`AttachConsole` / `AllocConsole` в release).

- Иконка принтера: `assets/icon.ico` (winres) и PNG для заголовка окна.
- Следующее: проверить GUI вручную; затем этап 2 — очистка очереди.

## 2026-09-16 — этап 1: stop / start / restart

- `spooler`: `stop_spooler` / `start_spooler` / `restart_spooler` через `ControlService` / `StartServiceW`.
- Ожидание целевого состояния с таймаутом 60 с, poll по `wait_hint` (MSDN 1–10 с), срыв при отсутствии прогресса checkpoint.
- Идемпотентность: stop при уже остановленной / start при уже работающей — успех без ошибки.
- Отказ в доступе → сообщение «запустите от имени администратора».
- CLI: `stop`, `start`, `restart`.
- Следующее: этап 2 — очистка очереди (`clear-queue` / `fix`).
