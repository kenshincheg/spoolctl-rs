# Удалённое управление (линия 0.2)

SpoolCtl управляет **другим ПК без своего агента**: через встроенные механизмы Windows.

## Как это работает

| Операция | Механизм |
|----------|----------|
| Статус / стоп / старт / перезапуск Spooler | `OpenSCManagerW(\\ИМЯ-ПК, …)` |
| Очистка очереди | `\\ИМЯ-ПК\ADMIN$\System32\spool\PRINTERS` |
| Список принтеров | `EnumPrinters` с именем сервера |

На удалённом ПК **не нужно** ставить SpoolCtl.

## Что нужно

1. Запуск SpoolCtl **от имени администратора** (на вашей машине).
2. Учётка с правами администратора на целевом ПК (домен / одна рабочая группа с паролем).
3. На целевом ПК в брандмауэре обычно:
   - «Удалённое управление журналом событий / службами» (Remote Service Management)
   - «Общий доступ к файлам и принтерам» (для `ADMIN$`)

## GUI

Поле **«Удалённый ПК»** в шапке. Пусто = этот компьютер.  
Сторож зависания и автоперезапуск работают **только для этого ПК** (пока удалённый хост выбран — сторож не трогает remote).

## CLI

```bat
SpoolCtl.exe --host OFFICE-PC status
SpoolCtl.exe --host 192.168.1.50 restart
SpoolCtl.exe --host OFFICE-PC fix
```

## Типичные ошибки

| Сообщение | Смысл |
|-----------|--------|
| RPC недоступен / 0x800706BA | ПК выключен, не в сети, или брандмауэр режет Remote Service Management |
| Отказано в доступе | Нужен запуск SpoolCtl от администратора и права админа на том ПК |

UI не блокируется на удалённых запросах: ответ приходит в фоне; пока идёт опрос, можно пользоваться окном.
